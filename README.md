# 🤖 BuildAI — AI-Powered App Builder

Build complete React applications using natural language. Describe your idea, and BuildAI generates the code, shows a live preview, and lets you improve or fix the app with AI.

Inspired by tools like **Lovable** and **Bolt.new**.

## ✨ Features

- 🧠 AI-powered React code generation
- ⚡ Live preview with Sandpack
- 💬 Persistent AI chat history
- 🖼️ Image upload support
- 🔧 AI-powered code improvement with Cline
- 🐛 Fix runtime and compile errors with AI
- 📦 Export projects as ZIP
- 💳 Credit-based plans
- 🔐 Authentication with Clerk
- 🗄️ Supabase/PostgreSQL database

## 🛠️ Tech Stack

- Next.js 15 + TypeScript
- Gemini AI
- Cline SDK
- Clerk
- Supabase + Prisma
- Sandpack
- Tailwind CSS
- Shadcn UI
- Arcjet
